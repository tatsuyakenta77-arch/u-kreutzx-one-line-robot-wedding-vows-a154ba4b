One line of wedding vows for a robot couple — a promise that survives every
firmware update and dead battery, right up to the factory reset.

## Run it

```sh
node main.ts
```

The program writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). It is fully deterministic: the same fixed text on every
run, with no randomness, no network and no clock.
